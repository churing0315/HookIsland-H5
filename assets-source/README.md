# 拉钩岛独立素材源文件目录

本目录用于保存正式制作阶段的独立、可编辑源文件，不作为网页公开加载目录。

建议结构：

- `scene/`：岛屿、海水、天空等分层源文件；
- `mascot/`：小伴龙各动作的独立源文件与关键帧；
- `items/`：每个建造物的静态、剪影、k1、k2；
- `ui/`：UI 图标、面板与功能图形；
- `fx/`：粒子和一次性特效；
- `audio/`：无损或高质量音频母版；
- `font/`：原始字体和许可记录。

当前阶段只使用程序生成的占位纹理，没有把角色设定图裁切成运行时精灵。后续加入正式素材时，必须为每项资源更新 `public/assets/asset-manifest.json`，并保留来源、生成版本和审核状态。
