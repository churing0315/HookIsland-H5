## 1. 角色识别锚点

后续所有站立、坐姿、睡眠、拉钩、庆祝、头像等素材必须保留：

1. 黄色圆润龙身和大头小身体比例；
2. 头顶红色双簇顶冠；
3. 头部左右两侧大面积红色鬃毛，正、侧、背视图轮廓一致；
4. 顶部左右黄色角/耳状附属结构；
5. 深棕色大椭圆眼、弧形眉、小鼻口和珊瑚色圆腮红；
6. 深棕色挂绳与蓝色圆形吊坠，吊坠带白色小高光；
7. 短小四肢、浅黄色腹部和足部高光；
8. 身后小型红色尾巴，尾端为三瓣/三叶状轮廓。

任何 AI 生成稿若缺失吊坠、改变顶冠数量、把侧鬃毛变成翅膀、改变尾端结构，均视为角色不一致，不得进入工程。

## 2. 三视图约束

### 正面

- 头部近圆形，宽度明显大于躯干；
- 两侧红色鬃毛基本对称；
- 吊坠位于胸前中线；
- 双臂自然下垂时不过度拉长；
- 双脚短圆，站姿重心稳定。

### 侧面

- 面部轮廓为圆弧，不做尖吻；
- 红色侧鬃毛覆盖后脑主要轮廓；
- 吊坠受重力垂在胸前，保持可辨识；
- 尾巴从身体后下方伸出，不与手臂混淆。

### 背面

- 红色鬃毛构成主要后脑轮廓；
- 黄色双角/耳状结构在顶冠两侧可见；
- 躯干和四肢保持黄色，尾端红色；
- 背面不凭空增加鳞片、翅膀或服装。

生产流程采用：

1. 先制作 `mascot_idle` 正面样张；
2. 与原图并排检查肤色、鬃毛、吊坠、眼睛和腮红；
3. 颜色偏差目标 ΔE≤5，且不得因场景昼夜改变角色固有色；
4. 六色即日起冻结；动作样张只验收造型、比例、分色和表情，不再任意改色；
5. 如未来提供权利方正式品牌色卡，再通过显式版本变更替换，禁止静默漂移。

## 4. 与项目视觉规范的适配

设定图使用柔和渐变、弱描边；项目 V1.0 规范要求扁平分色与统一暖深棕描边。执行优先级如下：

- **角色身份特征**以本设定图为准，不得为统一画风改变轮廓锚点；
- **工程表现方式**先按项目规范制作 2.5px 暖深棕描边和两阶分色样张；
- 不使用持续发光、噪点、复杂纹理或高对比阴影；
- 角色固有红/黄/蓝允许成为品牌色例外，但计时页仍不得引入额外高饱和 UI；
- 若扁平样张明显损失 IP 识别度，再保留极轻的固有色明暗过渡，不能扩展为场景通用渐变规则。

## 5. B 组动作生产约束

| 资源 | 动作要求 | 身份检查点 |
| --- | --- | --- |
| B01 待机 | 正面站立，4s 轻呼吸 | 吊坠居中、尾端可部分露出 |
| B02 坐姿 | 坐在色盘右下，轮廓安静稳定 | 鬃毛不遮挡色盘主要信息 |

| B05 拉钩 | 小拇指伸出并与儿童手指形成清晰接触 | 角色脸部保持高识别度 |
| B07 头像 | 正面友好表情 | 红色鬃毛和蓝吊坠至少保留一个强识别点 |
| B08 引导气泡 | 与头像/角色同屏使用 | 不烘焙角色进气泡底图 |

Demo 已移除独立勋章功能，因此 B06 不生产、不加载。

## 6. 动作一致性验收

- 各帧头身比、眼距、顶冠数量、吊坠尺寸和鬃毛外轮廓没有漂移；
- 镜像动作不得导致吊坠或尾巴结构错误；
- 拉钩关键帧手指清楚，但手部不能突然变成人类五指写实比例；
- 坐姿/睡眠姿态与 160×160 viewBox 相容，不裁切角、鬃毛或尾巴；
- 角色在 1×、2× DPR 下边缘清楚，无白边和颜色溢出；
- P4 连续观察 30 秒只出现规定的呼吸或睡眠 z 动画。
