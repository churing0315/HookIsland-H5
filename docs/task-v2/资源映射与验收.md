# 任务选择页面 V2 · 资源映射与验收

## 流程差异

- 新版正式入口：`TASK_SELECT → DURATION_SELECT → CONTRACT_CONFIRM → focus`。
- 长按满 1 秒后直接进入专注倒计时。
- 旧版 `beginRitual()` 与 2 秒仪式场景仍保留，没有删除；新版确认组件调用独立的 `confirmContract()`。

- 确认页沙漏使用用户补充的独立正式切图 `task_confirm_timeicon.png`，运行时路径为 `confirm-time-icon.png`；早期派生的 `hourglass.png` 仅保留兼容，不再被页面引用。

## 全局音频映射

| 文件 | 触发规则 |
| --- | --- |
| `click.wav` | 全局普通可点击按钮；已有自定义语音/音效的控件不叠加 |
| `birds-morning.wav` | 岛屿首页循环 BGM；首次用户交互后启动，离开岛屿暂停 |
| `confirmbtn.wav` | 确认页连续长按满 1 秒后播放一次 |
| `unableclick.wav` | 所有禁用或 `aria-disabled` 控件 |
| `homepinky.wav` | 已保留，尚未指定触发点 |

原始文件位于 `assets-source/audio/`，运行时文件位于 `public/assets/audio/`。

## 浏览器验收

- 8 项任务均可查看；鼠标拖动与触控拖动使用同一 Pointer Events 路径。
- 轮播非循环，两端停止；惯性衰减后吸附；中心/邻近/外侧为 0°/±3°/±5°。
- 卡片点击自动居中并选中；4 个时钟可选，旧选中项停止摆动。
- 快速重复点击不会重复创建时钟或确认组件。
- 450ms 短按、拖出按钮、取消触控均不会创建契约，进度回到 0。
- 1150ms 连续长按进入一次专注，任务与时长保持一致。
- 浏览器实测普通按钮加载 `click.wav`，灰色下一步加载 `unableclick.wav`，长按完成加载 `confirmbtn.wav`；任务/时长语音未叠加默认点击声。
- 岛屿首次交互加载并循环 `birds-morning.wav`，离开岛屿时由页面状态暂停。
- 桌面 1180×620、手机横屏 844×390 通过；控制台 0 warning / 0 error。
