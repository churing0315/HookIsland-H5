# 拉钩岛 Demo V2 · Codex 交接包

此包是 **现有可运行 Phaser + TypeScript + Vite 游戏工程的增量变更说明**，**不是源码，也不是已实现的新版游戏**。请将 docs 和 references 复制到你的实际游戏工程中（例如 docs/v2/ 与 docs/v2/references/），并在原 Codex 任务里执行 prompts 指令。不要新建空工程，不要覆盖现有的源代码或已有正式素材。

## 阅读顺序
1. `docs/V2-需求变更与验收.md`：这次新增的明确要求和建议待确认事项。
2. `docs/V2-美术资产清单.md`：素材分类、数量、命名和占格示例。
3. `prompts/01-增量改造地图与相机.md`：先实现真实的正俯视方格地图、阶段扩岛和缩放。
4. `prompts/02-素材库扩充与视觉集成.md`：第二轮处理单体素材和扩容素材库。
5. `references/` 五张参考图，原始文件未改动。

## 特别提示
- 新版正俯视 **覆盖旧版 2.5D 视觉约束**；地表为平面方格地图，建筑仍可采用二维卡通立面 sprite，不使用菱形等距网格。
- **保留 PRD 核心机制：一约一放、每日最多3次成功建造、第四次独立勋章、累计30/60分钟解锁、?fast=1。**
- 地图扩容条件建议为历史累计建造 3/9 次，而不是每天突破3次。最终以用户确认的策划参数为准。
- 图1已存在建筑，按 **初始公共地标（不消耗契约建造次数）** 理解，可与“初始没有玩家建造记录”的 PRD 一致；这是产品建议而非既定决策。
- 参考画面中的右上角“建造:4”应核查它是否表示历史总量，不能误当日进度；日进度单独展示“今日 0/3”。
- 图5《建筑.png》有 Alpha 通道，但存在大面积极低透明度残留，必须清理后按物件切图、验边、生成透明素材，不能当成已切好的 sprites 或整张背景。
- 当前仅拿到参考视觉图，**没有收到游戏源码/实际 GitHub 仓库**，因此本包不能直接修改用户线上 Demo。指令需要在持有工程的 Codex 任务中执行。
