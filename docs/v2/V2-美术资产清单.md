## 非建造型 / 初始公共地标
- 可以复用现有**橙顶小屋**和**邮局**作为默认岛屿地标；它们不消耗用户每日额度，也没有契约来源铭牌。
- 如果同类道具也在可建造清单中，需要不同 `instance_id` 与 `isLandmark` 数据字段，而不是共享一个已放置物品 ID。
- 岛屿水面、方格地形、沙滩和岩石 tile 不计入建造道具数目。

## 资源导出规范
- 单体 PNG/WebP（透明图），每件独立命名；除背景外无周边海水/地块底色。
- 绘制统一方向；Sprite 的视觉中心与地面占地 footprint 中心应能对齐；锚点按底部触地中心（或项目现有协议）保存。
- 使用实际素材尺寸确认占格，表内 footprint 只是起步建议；大型地标不可以为了塞进小岛随意缩成1格。
- 优先复用图5已有素材，质量不够可分批使用相同参考图重生，而非直接采用含脏底的整张表。
- 具体资源像素尺寸/打包策略由 Codex 在目标分辨率与5MB预算下估算；需保留审稿版和压缩运行版。
